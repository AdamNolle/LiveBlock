# LiveBlock interface direction

LiveBlock is a repeated-use desktop utility. Its first job is to make the
current blocking state clear and let someone mark a region in one action.

Use the precision-software direction from Adam's design-ui skill: Raycast's
focused command surface informs density and hierarchy; Forge informs measured
type and a restrained accent. Keep the existing pixel-grid app mark and blue
brand accent. These are design references, not copied product assets.

macOS uses system-adaptive text and materials, native settings navigation,
SF Symbols and Liquid Glass for the primary control. Use one primary action,
quiet secondary actions, compact tabular statistics, and readable status text.
Training separates progress, configuration and diagnostic logs. Labeling keeps
the screenshot dominant and labels explicit.

Windows/Linux share the hierarchy with adaptive light/dark colors, thin
boundaries, visible keyboard focus, and consistent utility icons. Remove fake
performance numbers and nonfunctional controls. Use 10/16/22-pixel corners
with shadows only on elevated chrome. Fonts are system UI and monospaced
numerals, with no remote font dependency.

Empty, busy, permission-denied, failure and completion states need clear next
actions. Do not imply all objects are ads, training guarantees accuracy, or
capture reads protected video. Narrow windows stack actions and reduce stats
columns. Respect reduced motion and increased contrast. Review actual rendered
macOS and browser states; native Windows/Linux checks require those platforms.
