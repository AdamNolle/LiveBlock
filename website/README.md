# LiveBlock website

Static, dependency-free launch site. Serve this directory with any static HTTP
server. For a local preview from the repository root:

```powershell
python -m http.server 8765 --directory website
```

The product graphic and interactive region example are **illustrations**, not
recorded application footage or evidence that a detector works. The site links
to source and release evidence, and does not offer a production download.

Visual language follows the current v4 native `Sources/Theme.swift` and
`design/project/tokens.css` rather than the historical v3 brutalist study.
The logo is copied from `models/liveblock-icon.svg`. Bundled Geist fonts and
their SIL Open Font License were copied from `Sources/Resources/Fonts/`.

No site deployment configuration or verified domain existed in this repository
when this website was created. Host it as a static directory after choosing a
publication route; add the verified URL to repository metadata only after the
site is live.
